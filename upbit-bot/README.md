# 업비트 비트코인 50일선 추세추종 봇

## 규칙
하루 한 번, 업비트 일봉이 바뀌는 **오전 9시(KST) 이후**에 판단합니다.

- **어제 종가 > 50일선**(최근 50일 종가 평균) → **보유**: 원화가 있으면 전부 비트코인으로 삽니다.
- **어제 종가 ≤ 50일선** → **현금**: 비트코인을 전부 팝니다.
- 매달 10일 전후로 **원화 10만 원만 입금**하면 됩니다. 보유 신호면 바로 사고, 현금 신호면 신호가 바뀔 때까지 원화로 기다립니다.

업비트 일봉 백테스트 (매달 10일 10만 원, 수수료 포함, `python backtest.py`로 재현 가능):

| 기간 | 넣은 돈 | 매달 사서 보유 | 50일선 추세추종 |
|---|---|---|---|
| 3년 (2023-11 ~ 2026-11) | 370만 원 | 366만 원 (-1.2%) | **523만 원 (+41.5%)** |
| 6년 (2021-01 ~ 2026-11) | 710만 원 | 1,242만 원 (+74.9%) | **2,211만 원 (+211%)** |
| 상승장만 (2023-11 ~ 2025-10) | 230만 원 | **425만 원 (+84.9%)** | 411만 원 (+78.8%) |

강한 상승장에서는 보유보다 조금 덜 벌고, 하락장에서 현금으로 피해 있으면서 차이를 만듭니다. 과거 결과가 앞으로를 보장하지 않습니다.

## 기존 보유분은 건드리지 않습니다
- 봇은 **자기가 산 비트코인만** 장부(`state.json`의 `bot_btc`)에 적고, 현금 신호일 때 **그만큼만** 팝니다.
  원래 갖고 있던 비트코인은 그대로 둡니다.
- 원화는 `KRW_RESERVE`를 뺀 **전부를 봇이 씁니다.** 다른 용도로 둔 원화가 있으면 그 금액을 `KRW_RESERVE`에 적으세요.
- 기존 비트코인을 직접 팔면 그 원화도 봇이 쓰게 됩니다. 쓰지 않을 돈이면 출금하거나 `KRW_RESERVE`를 올리세요.
- 다른 코인은 건드리지 않습니다. `python bot.py status`에서 봇 보유분과 기존 보유분을 따로 보여줍니다.

## 처음부터 적용하기

### 1단계. 실행할 곳 정하기
업비트 API 키는 **미리 등록한 IP에서만** 작동합니다. 그래서 IP가 고정된 곳에서 돌려야 합니다.
- **추천: 클라우드 서버** (오라클 클라우드 무료 VM, AWS Lightsail 월 5달러 등). 고정 IP가 있고 24시간 켜져 있습니다.
- **집 컴퓨터**: 가능하지만 매일 아침 9시 이후에 켜져 있어야 합니다. 공유기 IP가 바뀌면 업비트에 다시 등록해야 합니다.

### 2단계. 코드 받기
```bash
git clone -b claude/gracious-bohr-3ptidb https://github.com/1992405-spec/new.git
cd new/upbit-bot
pip install -r requirements.txt
```

### 3단계. 업비트 API 키 발급
업비트 웹 → 마이페이지 → Open API 관리
- 권한: **자산조회, 주문조회, 주문하기**만 체크합니다. **출금하기는 절대 체크하지 마세요.**
- 허용 IP: 1단계에서 정한 곳의 IP를 넣습니다. 서버에서 `curl ifconfig.me`를 실행하면 나옵니다.
- Secret Key는 **발급할 때 한 번만** 보여주니 바로 복사해 두세요.

### 4단계. 설정 파일
```bash
cp .env.example .env
chmod 600 .env          # 나만 읽을 수 있게
nano .env               # 키 두 개 붙여넣기, DRY_RUN=1 유지
```
업비트에 다른 용도로 둔 원화가 있으면 그 금액을 `KRW_RESERVE`에 적습니다.

### 5단계. 확인
```bash
python bot.py check     # "API 키 정상" 이 나와야 함
python bot.py status    # 신호, 50일선, 봇 보유분과 기존 보유분
```

### 6단계. 모의투자 며칠
```bash
python bot.py once      # 실제 주문 없이 기록만 (state_paper.json)
```

### 7단계. 실전 주문 시험 (6,000원)
```bash
python bot.py test-order   # 6,000원 사고 바로 팔기, 비용 약 6원
```
매수와 매도가 모두 체결되면 실전 주문 경로가 정상입니다.

### 8단계. 실전 시작
1. `.env`에서 `DRY_RUN=0`으로 바꿉니다.
2. `crontab -e`로 아래 줄을 추가합니다. 하루 4번 확인하고, 입금된 돈도 이때 삽니다.
   ```
   5 9,12,18,22 * * * cd $HOME/new/upbit-bot && /usr/bin/python3 bot.py once >> cron.log 2>&1
   ```
   서버 시간대가 한국이 아니면 `CRON_TZ=Asia/Seoul`을 위에 한 줄 추가하세요.
3. 매달 10일 전후로 업비트에 원화를 입금합니다.
4. 가끔 `python bot.py status`나 `bot.log`로 확인합니다. 텔레그램을 설정하면 매수·매도 알림이 옵니다.

## 보안
- **출금 권한이 없는 키**라서, 키가 새어 나가도 남이 돈을 빼갈 수는 없습니다. 최악의 경우 마음대로 사고파는 정도입니다.
- **IP 제한** 때문에 등록한 IP가 아닌 곳에서는 키가 작동하지 않습니다.
- 키는 `.env`에만 있고, `.env`는 git에 올라가지 않습니다. 봇은 키를 업비트(`api.upbit.com`)에만 보냅니다.
- 키가 노출됐다고 의심되면 업비트에서 그 키를 **바로 삭제**하고 새로 발급하세요.
- 키에는 유효기간이 있습니다. 만료되면 봇이 오류를 내니, 다시 발급해서 `.env`를 바꾸세요.

## 주의

- 텔레그램 알림을 설정하면 매수, 매도, 신호 변경, 오류를 알려줍니다.
