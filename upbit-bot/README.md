# 업비트 비트코인 묶음 단타 봇

## 규칙
- 매달 **10일에 10만 원**으로 비트코인을 사서 **묶음(lot)** 하나를 만든다.
- 묶음마다 **자기 매수가 +0.5%**가 되면 그 묶음만 팔고, 받은 돈 전부로 바로 다시 산다.
- 가격이 떨어지면 기다린다 (손절 없음). 비싸게 산 묶음이 묶여 있어도, 싸게 산 새 묶음은 계속 돌아간다.

수수료(0.05% x 2)를 빼면 한 번에 실제로 남는 건 **약 0.45%** 입니다.

## 1. 설치
```bash
cd upbit-bot
pip install -r requirements.txt
cp .env.example .env      # 키 입력
```

업비트 → 마이페이지 → Open API 관리에서 키 발급:
- 권한: **자산조회, 주문조회, 주문하기**만. **출금은 끄세요.**
- 봇을 돌릴 컴퓨터/서버의 **IP 주소**를 등록해야 합니다.

## 2. 먼저 백테스트
```bash
python backtest.py --years 2            # 1시간봉으로 최근 2년
python backtest.py --years 3 --unit 10  # 10분봉, 더 정확
```
"그냥 매달 사서 보유"와 비교해 줍니다. 가장 오래 묶인 기간, 최악 평가손실도 꼭 보세요.

## 3. 모의투자 (DRY_RUN=1, 기본값)
```bash
python bot.py run
```
실제 주문 없이 현재가로 체결됐다고 치고 `state_paper.json`에 기록합니다. 며칠 돌려보세요.

## 4. 실전
1. 지금 가진 비트코인이 있으면 묶음으로 등록 (매수 평균가, 수량은 업비트 거래내역에서 확인):
   ```bash
   DRY_RUN=0 python bot.py add-lot --price 145000000 --volume 0.00068
   ```
   묶음마다 따로 등록하면 묶음마다 따로 팔립니다. 하나로 등록하면 평균가 기준으로 한 번에 팔립니다.
2. `.env`에서 `DRY_RUN=0` 으로 바꾸고 `python bot.py run`
3. 매달 10일 전에 업비트에 **원화 10만 원을 입금**만 하면 됩니다. 돈이 없으면 입금될 때까지 기다렸다 삽니다.

현황 보기: `python bot.py status`

## 주의
- **봇이 장부(`state.json`)에 적은 묶음만** 사고팝니다. 직접 산 코인은 `add-lot`으로 등록하지 않으면 건드리지 않습니다.
  반대로 봇이 산 코인을 직접 팔면 장부와 맞지 않으니, 그럴 땐 `remove-lot --id N`으로 지우세요.
- 컴퓨터가 꺼지면 봇도 멈춥니다. 24시간 돌리려면 클라우드 서버(예: 오라클 클라우드 무료 VM, AWS Lightsail)에
  올리고 `nohup python bot.py run &` 또는 systemd로 실행하세요. 서버 IP를 업비트에 등록해야 합니다.
- 이 저장소는 GitHub Pages로 공개되어 있을 수 있습니다. **키는 `.env`에만** 넣으세요 (git에 안 올라가게 막혀 있음).
- 손절이 없는 전략이라 비트코인이 크게 떨어지면 오래 묶입니다. 투자 판단과 책임은 본인에게 있습니다.
