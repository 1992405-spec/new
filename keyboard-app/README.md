# AI 번역 키보드

아이폰 어디서든 글을 선택하고 **GPT나 Claude로 번역해서 그 자리에서 바꿔 주는** 키보드예요.

## 키보드 버튼

| 버튼 | 하는 일 |
|---|---|
| **번역으로 대체** | 선택한 글을 번역문으로 바꿔요 |
| **앞 글 전부 번역** | 커서 앞의 글을 통째로 번역해서 바꿔요. 선택을 알려주지 않는 앱에서 쓰세요 |
| **복사한 글 번역해 넣기** | 클립보드에 있는 글을 번역해서 커서 위치에 넣어요 |
| **되돌리기** | 방금 바꾼 번역을 원문으로 돌려요 |
| **→ 한국어** | 번역할 언어와 두 번째 언어를 맞바꿔요 |
| 🌐 · space · ⌫ · ↵ | 키보드 전환, 띄어쓰기, 지우기, 줄바꿈 |

글은 이 키보드로 치지 않아요. 평소 키보드로 쓰다가 🌐로 잠깐 바꿔서 번역하고 다시 돌아가는 방식이에요.

## 설치 (맥 필요)

1. 맥에 **Xcode**(App Store)와 **XcodeGen**을 설치해요.
   ```sh
   brew install xcodegen
   ```
2. `project.yml`에서 `BUNDLE_PREFIX: com.example.aikeyboard`를 본인만의 값(예: `com.myname.aikeyboard`)으로 바꿔요.
3. 이 폴더에서 프로젝트를 만들고 열어요.
   ```sh
   cd keyboard-app
   xcodegen generate
   open AIKeyboard.xcodeproj
   ```
4. Xcode에서 **AIKeyboard**와 **TranslateKeyboard** 타깃을 각각 열고, *Signing & Capabilities*의 **Team**에서 본인 Apple ID를 골라요.
5. 아이폰을 케이블로 연결하고 ▶︎ 실행해요.
   - 처음이면 아이폰에서 *설정 → 개인정보 보호 및 보안 → 개발자 모드*를 켜야 해요.
   - *설정 → 일반 → VPN 및 기기 관리*에서 개발자 앱을 신뢰해 줘야 할 수 있어요.

> 무료 Apple ID로 설치하면 **7일마다** 다시 실행해서 설치해야 해요. 유료 개발자 계정(연 $99)이면 1년 동안 유지돼요.

## 사용 준비

1. 설치된 **AI 번역 키보드** 앱을 열어 AI(GPT/Claude)를 고르고 API 키를 넣은 뒤 **저장**해요. **번역해 보기**로 잘 되는지 확인할 수 있어요.
   - GPT 키: platform.openai.com → API keys
   - Claude 키: console.anthropic.com → API Keys
2. *설정 → 일반 → 키보드 → 키보드 → 새로운 키보드 추가*에서 **AI 번역**을 추가해요.
3. 추가한 **AI 번역**을 눌러 **전체 접근 허용**을 켜요. 번역 서버에 연결하려면 꼭 필요해요.

## 알아둘 점

- API 키는 기기 키체인에만 저장되고, 번역할 글은 선택한 AI 회사 서버로만 전송돼요.
- 비밀번호 입력창이나 일부 앱(은행 앱 등)에서는 iOS가 서드파티 키보드를 막아요.
- 어떤 앱은 선택한 글을 키보드에 알려주지 않아요. 그럴 땐 **앞 글 전부 번역**이나 **복사한 글 번역해 넣기**를 쓰세요.
- 기본 모델은 `gpt-5-mini`, `claude-haiku-5-5`예요. 앱의 모델 칸에서 바꿀 수 있어요.
